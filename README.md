Live at https://brendakinoti-datascientist.netlify.app/

Plain HTML, CSS and a little JavaScript. No build step: Netlify serves this folder as it is.

## Editing

- **Text**: everything is in `index.html`, one clearly marked block per section.
- **Photo**: replace `assets/img/brenda.jpg` with a square image.
- **Paper PDFs**: put the file in `papers/` and add a link under that paper's summary (there is a comment in `index.html` showing how).
- **CV**: replace `assets/Brenda-Ntinyari-Kinoti-CV.pdf`.
- **Colors and fonts**: the variables at the top of `assets/css/style.css`.
